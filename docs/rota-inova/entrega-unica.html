Foto: R. Henrik Nilsson, Wikimedia Commons, CC BY 4.0

O que o teste precisa provar

Três perguntas. Se uma falhar, a ideia muda

É mais rápido?

Achar e conferir uma peça leva menos tempo do que hoje.

É seguro?

Quando responde sozinha, a AgroParts deve errar menos de 1 vez em cada 100. Se errar mais, ela passa mais casos para uma pessoa.

É possível?

Uma usina aceita mostrar a lista de peças para o teste.

Como funciona

Do código à resposta, em quatro passos

1. EntradaA pessoa digita o código ou fotografa a etiqueta.
2. BuscaA AgroParts procura a peça no catálogo.
3. ComparaConfere as medidas, uma por uma.
4. RespostaÉ a mesma, não é, ou precisa de uma pessoa.

Fora do teste, por enquanto

O que fica para depois

Comprar sozinho

A compra continua com as pessoas e o sistema da usina.

Ligar direto no sistema da usina

O teste usa uma planilha. Nada é gravado no sistema.

Outros tipos de peça

Bombas e vedações vêm depois do rolamento.

Reconhecer a peça só pela foto

A aparência não mostra a medida. A foto serve para ler a etiqueta.

Prototipagem

O protótipo funcionando, com dados públicos.

O protótipo

Uma pergunta: qual é esta peça?

A pessoa digita o código, a descrição ou manda a foto da etiqueta.

agroparts.pages.dev

Caso 1

Dois cadastros, a mesma peça

O protótipo encontra dois cadastros do mesmo rolamento e mostra por quê.

Caso 2

Parece, mas não é

Sete peças com nome quase igual. O protótipo recusa e mostra a diferença de cada uma.

Caso 3

Outra marca, mesma medida

O cadastro cita duas marcas com a mesma medida. Trocar uma pela outra? Uma pessoa confere antes.

Caso 4

A lista inteira de uma vez

396
peças de uma lista pública, lidas em um clique
28
grupos de cadastros repetidos

Caso 5

O cadastro se contradiz

O texto diz 60 mm. O código diz 65 mm. A pessoa decide, e o sistema guarda quem decidiu e por quê.

A câmera

A foto serve para ler a etiqueta

No celular

Funciona no celular, no meio do almoxarifado

Resultados até agora

No teste, o protótipo não confundiu nenhuma peça

90 de 90
peças parecidas, mas diferentes, foram recusadas
14 de 14
pares da mesma peça foram encontrados
0
trocas de marca feitas sem uma pessoa

Foi um teste pequeno, com dados públicos do governo. O próximo passo é testar com a lista de uma usina.

Limites

O que o protótipo ainda não faz

Dados de uma usina

Usa só dados públicos. Ainda não provou valor para uma usina.

Catálogo do fabricante

Os termos de fabricantes como SKF e Timken não deixam usar os dados sem autorização.

Compra

Não faz pedido e não grava nada no sistema da usina.
